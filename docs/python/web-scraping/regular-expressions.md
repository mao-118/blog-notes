元字符: 具有固定含义的特殊符号常用元字符:

. 匹配除换行符以外的任意字符

WwW 匹配字母或数字或下划线

\s 匹配任意的空白符

xd 匹配数字

### An 匹配一个换行符

### \t 匹配一个制表符

A 匹配字符串的开始

$ 匹配字符串的结尾

OW 匹配非字母或数字或下划线

### \D 匹配非数字

### \S 匹配非空白符

### alb "匹配字符 aq 或字符 b

### © 匹配括号内的表达式， 也表示一个组

|...] 匹配字符组中的字符

[^A...] 匹配除了字符组中字符的所有字符

### 量词: 控制前面的元字符出现的次数

* 重复零次或更多次

二重复一次或更多次

2 重复零次或一次

重复 n 次

{n,} 重复 n 次或更多次

yn, 只重复 n 到 m 次

贪楚匹配和惰性匹配

i 贪禁匹配

.*? 惰性匹配

### 这两个要着重的说一下. 因为我们写爬虫用的最多的就是这个惰性匹
